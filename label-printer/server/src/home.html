Zebra label printing

Print labels from any product: open the product, tap More actions → Print labels. For several products, select them in the product list and choose Print labels from the bulk actions.

Connecting a printer

  1. Put the printer on Wi-Fi with the Zebra Printer Setup Utility app.
  2. Set its Weblink location to %WEBLINK_BASE%<printer token> (the token is in the server's PRINTERS setting).
  3. Restart the printer. It shows up here as connected within a minute.
